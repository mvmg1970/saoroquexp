# SAOROQUE_XP

Webchat de turismo inteligente para **São Roque/SP**.

## Objetivo do projeto
- orientar visitantes
- recomendar experiências por perfil
- capturar leads para atendimento humano
- evoluir depois para reservas e transações

## MVP
- chat-first mobile
- FAQ turístico
- recomendação curada por perfil
- captura de nome/WhatsApp/interesse
- handoff humano
- métricas básicas
