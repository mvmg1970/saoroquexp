# PRD MVP — SAOROQUE_XP

## Escopo
- chat-first mobile
- FAQ turístico
- recomendação curada por perfil
- captura de lead
- handoff humano
- métricas básicas

## Fora do escopo
- checkout no chat
- split de pagamento
- booking automatizado
- mini-apps complexos
- multimodal pesado
- integrações CRM avançadas

## Fluxo principal
1. usuário pergunta algo
2. sistema identifica perfil/roteiro
3. responde com até 3 sugestões
4. pede contato se houver intenção comercial
5. encaminha para humano
